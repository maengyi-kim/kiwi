## 一、STM32 Blue Pill 引脚总览

```
                     STM32F103C8T6 Blue Pill
                    ┌─────────────────────────┐
                    │         USB-C           │
                    │  ┌───────────────────┐  │
               RST──┤○ │                   │ ○├──3.3V
               3.3V─┤○ │                   │ ○├──GND
               GND──┤○ │                   │ ○├──5V
                    │  │                   │  │
              PA0 ──┤○│○                   │○│○├── PB12  ── SX1278 NSS
              PA1 ──┤○│○                   │○│○├── PB13  ── SX1278 SCK
              PA2 ──┤○│○                   │○│○├── PB14  ── SX1278 MISO
                    │  │                   │  │
              PA9 ──┤○│○    STM32F103      │○│○├── PB15  ── SX1278 MOSI
             PA10 ──┤○│○    C8T6           │○│○├── PB0   ── SX1278 RST
                    │  │                   │  │
              PB1 ──┤○│○                   │○│○├── PC13  ── 板载LED
              PB6 ──┤○│○                   │○│○├── PB7
                    │  └───────────────────┘  │
                    │       BOOT0 BOOT1        │
                    │       [●=1] [○=0]        │
                    └─────────────────────────┘

  引脚分配:
    PA0   → DHT22 DATA
    PA1   → 外接LED（预留）
    PA2   → 电池电压ADC
    PA9   → CH340 RX（烧录）
    PA10  → CH340 TX（烧录）
    PB0   → SX1278 RST
    PB1   → SX1278 DIO0
    PB6   → HC-SR04 TRIG（水位计用）
    PB7   → HC-SR04 ECHO（水位计用）
    PB12  → SX1278 NSS
    PB13  → SX1278 SCK
    PB14  → SX1278 MISO
    PB15  → SX1278 MOSI
    PC13  → 板载LED（心跳指示）
```

## 二、烧录接线 — CH340 → STM32

```
  ┌──────────────┐              ┌─────────────────┐
  │   CH340      │              │  STM32 Blue Pill │
  │  USB-TTL     │              │                  │
  │              │              │                  │
  │   TX  ────────────────────── PA10 (RX)         │
  │   RX  ────────────────────── PA9  (TX)         │
  │  3.3V ────────────────────── 3.3V              │
  │  GND  ────────────────────── GND               │
  │              │              │                  │
  │  USB ═══════ PC             │  BOOT0=1 ▸编程   │
  └──────────────┘              └─────────────────┘

  烧录: BOOT0=1 → pio run -t upload → BOOT0=0 → RESET
```

## 三、DHT22 温湿度传感器 → STM32

```
  ┌──────────────────┐          ┌─────────────────┐
  │  DHT22 模块       │          │  STM32 Blue Pill │
  │  (带小板)         │          │                  │
  │                   │          │                  │
  │  VCC (pin1) ──────────────── 3.3V              │
  │  DATA(pin2) ──────────────── PA0               │
  │  NC  (pin3) ─── 不接       │                  │
  │  GND (pin4) ──────────────── GND               │
  └──────────────────┘          └─────────────────┘

  注意: 模块自带4.7kΩ上拉电阻，不需外加
```

## 四、SX1278 LoRa 模块 → STM32

```
  ┌──────────────────┐          ┌─────────────────┐
  │  SX1278 RA-02     │          │  STM32 Blue Pill │
  │                   │          │                  │
  │  VCC  ────────────────────── 3.3V              │
  │  GND  ────────────────────── GND               │
  │  NSS  ────────────────────── PB12              │
  │  SCK  ────────────────────── PB13              │
  │  MOSI ────────────────────── PB15              │
  │  MISO ────────────────────── PB14              │
  │  RST  ────────────────────── PB0               │
  │  DIO0 ────────────────────── PB1               │
  │                   │          │                  │
  │  ANT  ═══ 弹簧天线 │          │                  │
  └──────────────────┘          └─────────────────┘

  ⚠️ 天线必须先接！不接天线发射会烧功放芯片
  ⚠️ SX1278 峰值电流 120mA，如果 Blue Pill 板载 3.3V 不稳，
     加独立 AMS1117-3.3 供电
```

## 五、HC-SR04 超声波 → STM32（水位计用）

```
  ┌──────────────────┐          ┌─────────────────┐
  │  HC-SR04          │          │  STM32 Blue Pill │
  │                   │          │                  │
  │  VCC  ─────────────────────── 5V（必须5V！）    │
  │  TRIG ─────────────────────── PB6              │
  │  ECHO ───[1kΩ电阻]─────────── PB7              │
  │  GND  ─────────────────────── GND              │
  └──────────────────┘          └─────────────────┘

  ⚠️ ECHO 返回 5V 电平，必须串 1kΩ 电阻再入 PB7，否则烧 STM32 引脚
  ⚠️ VCC 必须 5V，3.3V 不工作
  
  如果用防水款 JSN-SR04T：3.3-5V 均可，不需要串联电阻
```

## 六、电池分压检测 → STM32

```
  ┌─────────────────┐
  │  18650 锂电池    │
  │  (+)  ──┬───────┤
  │         │        │
  │        100kΩ     │
  │         │        │
  │         ├─────────────── STM32 PA2 (ADC)
  │         │        │
  │        100kΩ     │
  │         │        │
  │  (-) ──┴─────── GND
  └─────────────────┘

  电池电压 = ADC读数 × 3.3V / 4096 × 2
  例: 3.7V 电池 → 分压 1.85V → ADC ≈ 2295
```

## 七、电池供电链（部署用）

```
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌─────────────────┐
  │ 18650    │    │ TP4056   │    │ MT3608   │    │ STM32 Blue Pill │
  │ 锂电池   │    │ 充电保护  │    │ 升压模块  │    │                 │
  │          │    │          │    │          │    │                 │
  │ (+)──────┼───→│ IN+  OUT+│───→│ IN+  OUT+│───→│ 5V/USB          │
  │ (-)──────┼───→│ IN-  OUT-│───→│ IN-  OUT-│───→│ GND             │
  └──────────┘    │          │    │          │    └─────────────────┘
                  │  USB-C   │    │  (调5V)  │
                  │  (充电口) │    │          │
                  └──────────┘    └──────────┘

  ⚠️ 先万用表调 MT3608 输出 5V，再接开发板！
```
