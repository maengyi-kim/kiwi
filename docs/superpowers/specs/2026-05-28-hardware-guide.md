### 2.2 分步搭建

**第1步：最小系统通电**

```
Blue Pill 需要：
  - USB 供电（micro USB 口，接 5V 充电器或电脑）
  - 或用 ST-Link 的 3.3V 供电
  - 板载 LED PC13 应该闪烁（烧了 blink 程序后）

板上跳线帽：确认 BOOT0=0, BOOT1=0（从 Flash 启动）
```

**第2步：接 DHT22 温湿度传感器**

```
DHT22 (4针脚，从左到右)：
  1. VCC  ── 3.3V
  2. DATA ── PA0 + 4.7kΩ 上拉电阻到 3.3V
  3. NC   ── 不接
  4. GND  ── GND

注意：DATA 脚必须接 4.7kΩ 上拉电阻！
DHT22 模块（带小板的）通常已内置上拉电阻，不用外加。
```

**第3步：接 HC-SR04 超声波**

```
HC-SR04 (4针脚)：
  VCC  ── 5V（注意：必须 5V！3.3V 不起作用）
          但 STM32 是 3.3V 电平，ECHO 返回 5V 可能烧引脚。
          解决：ECHO 脚串一个 1kΩ 电阻再接入 PB7。

  TRIG ── PB6
  ECHO ── PB7（经 1kΩ 电阻限流）
  GND  ── GND

  JSN-SR04T（防水款）：同上，3.3-5V 均可，更安全。
```

**第4步：接 SX1278 LoRa 模块**

```
SX1278 RA-02 (8针脚)：
  VCC   ── 3.3V
  GND   ── GND
  NSS   ── PB12
  SCK   ── PB13
  MOSI  ── PB15
  MISO  ── PB14
  RST   ── PB0
  DIO0  ── PB1

重要：
  - 天线必须接！不接天线发射可能烧模块。
  - 模块供电要稳，3.3V 峰值电流可达 120mA。
    如果 Blue Pill 板载 3.3V 不稳，加一个 AMS1117-3.3 独立供电。
```

**第5步：电池电压检测**

```
电池 + ──── R1(100kΩ) ────┬──── R2(100kΩ) ──── GND
                           │
                          PA2 (ADC读取分压)

  电池电压 = ADC值 * 3.3V / 4096 * (R1+R2)/R2
           = ADC值 * 3.3 / 4096 * 2

  例：电池 3.7V，分压 1.85V，ADC 读 ~2295
```

### 2.3 供电方案

```
方案A：USB 供电（推荐调试阶段）
  任何 5V USB 充电器 → Blue Pill micro USB
  优点：简单、稳定
  缺点：必须附近有插座

方案B：18650 锂电池（推荐生产部署）
  18650 电池(3.7V) → TP4056 充电模块 → 升压模块 MT3608(→5V) → Blue Pill
                     ▲                         │
                     │                         └──→ 5V 也供 HC-SR04
                     └── USB口（定期充电）

  组件清单：
  - 18650 锂电池(2600mAh)  ¥10
  - TP4056 充电保护板      ¥3
  - MT3608 升压模块         ¥5
  
  估算续航（2600mAh，每5分钟唤醒一次，每次2秒@30mA）：
  平均电流 ≈ (30mA × 2s + 20μA × 298s) / 300s = 0.22mA
  续航 ≈ 2600 / 0.22 ≈ 11800 小时 ≈ 490 天
  实际约 6-12 个月（考虑自放电和升压损耗）

方案C：外接 12V 电源 + 降压模块（冷库附近有电源时）
  12V 开关电源 → LM2596 降压模块(→5V) → Blue Pill USB
  优点：不用换电池
  缺点：必须布线
```

## 三、LoRa 网关：硬件搭建

### 3.1 方案一：Heltec WiFi LoRa 32 V3（推荐）

一体化板，ESP32 + SX1262 + OLED + WiFi 全集成，不需要额外接线。

```
上电 → 连 WiFi → 开始监听 LoRa → OLED 显示收到的数据包数

引脚（如需外接）：
  OLED 已内置
  LoRa 已内置
  可用 GPIO：根据板子版本，一般 GPIO 2,4,12-15,21,22,25-27 等

调试：USB 直接烧录，Arduino IDE 选 "Heltec WiFi LoRa 32(V3)"
```

### 3.2 方案二：ESP32 + 独立 SX1278（成本优先）

接线：

```

  3.3V  ──────────── VCC
  GND   ──────────── GND
  GPIO5 ──────────── NSS
  GPIO18 ─────────── SCK
  GPIO19 ─────────── MISO
  GPIO23 ─────────── MOSI
  GPIO14 ─────────── RST
  GPIO26 ─────────── DIO0
```

## 四、天线

### 4.1 天线选择

| 类型 | 增益 | 尺寸 | 适用场景 | 价格 |
|------|------|------|----------|------|
| 弹簧天线 | 2-3 dBi | 5cm | 节点用，小体积 | ~¥3 |
| 胶棒天线 | 3-5 dBi | 10-20cm | 网关用，高增益 | ~¥8 |
| PCB天线 | 1-2 dBi | 板载 | 超小体积 | ~¥0 |

推荐：节点用弹簧天线，网关用胶棒天线。

### 4.2 天线安装

```
节点：弹簧天线竖直向上，远离金属物体 20cm 以上。
     不要贴在冷库金属墙上。

网关：胶棒天线用 SMA 转接线引出，放高处。
     如办公室窗口、走廊天花板。越高越好。
     
避雷：室外天线需防雷，室内不需要。
```

## 六、调试流程

### 6.1 先调通一个节点（最小闭环）

```
Day 1:
  1. STM32 Blue Pill → 烧 blink 程序 → LED 闪烁 ✓
  2. 接 DHT22 → 串口打印温湿度 → 读数正确 ✓
  3. 接 SX1278 → 两块板互发"Hello" → 收到 ✓

Day 2:
  4. 网关 ESP32 → 连 WiFi → 连 MQTT Broker → 收到测试消息 ✓
  5. 节点发数据 → 网关收到 → MQTT 上云 → PostgreSQL 有记录 ✓
  6. Grafana 配数据源 → 画出曲线 ✓

Day 3:
  7. 调功耗 → 测耗电 → 算续航
  8. 加电池 → 断电跑 → 看能撑多久
  9. 稳定性测试 → 跑 24 小时不掉数据
```

### 6.2 常见问题

| 问题 | 可能原因 | 排查 |
|------|----------|------|
| DHT22 读不到数据 | 上拉电阻没接 | 万用表测 DATA 脚是否 3.3V |
| DHT22 读数全是 0 | 时序不对 | 检查延时函数是否准确 |
| LoRa 收不到 | 天线没接 | 接上天线再试 |
| LoRa 距离短 | 发射功率太低 | 调至 17-20dBm |
| HC-SR04 不准 | 供电不足 | 用独立 5V 供电 |
| STM32 不启动 | BOOT0 没拉低 | 跳线帽 BOOT0=0 |
| 烧录失败 | 串口驱动 | CH340 驱动装了没 |

## 八、到货后接线（交接文档）

> **重要：以下步骤在本地电脑的 Hermes 上执行，不是在服务器上。**
> 本地电脑需要连接 USB 给开发板烧录和调试。

### 8.1 到货检查

- [ ] 所有 12 项物品齐全
- [ ] STM32 板接 USB → 板载 LED 亮
- [ ] ESP32 网关板接 USB → OLED 亮
- [ ] 18650 电池电压 ≥ 3.6V（万用表测）

### 8.2 第一步：STM32 最小系统验证

```
接线：CH340 USB-TTL → STM32 烧录口
  CH340 TX  ──  STM32 PA10 (RX)
  CH340 RX  ──  STM32 PA9  (TX)
  CH340 3.3V ── STM32 3.3V
  CH340 GND ──  STM32 GND

STM32 跳线帽：BOOT0=1（编程模式）
烧完 blink → BOOT0=0（运行模式）→ 板载 PC13 LED 闪烁 ✓
```

### 8.3 第二步：DHT22 接线验证

```
DHT22 → STM32：
  VCC  ── 3.3V
  DATA ── PA0（模块自带 4.7kΩ 上拉）
  GND  ── GND

烧测试程序 → 串口打印温湿度 → 读数合理 ✓
```

### 8.4 第三步：SX1278 LoRa 通信

```
SX1278 → STM32：
  VCC  ── 3.3V
  GND  ── GND
  NSS  ── PB12
  SCK  ── PB13
  MISO ── PB14
  MOSI ── PB15
  RST  ── PB0
  DIO0 ── PB1
  接天线！

先两端互发 "Hello" → 收到 ✓
测距离 → 厂区覆盖 OK ✓
```

### 8.5 第四步：网关 ESP32 验证

```
ESP32 上电 → OLED 亮 → 连 WiFi → 连 MQTT Broker → 串口打印状态 ✓
收到节点 LoRa 数据 → 串口打印 → MQTT 发布 → 服务器收到 ✓
```

### 8.6 第五步：电池供电

```
接线：
  18650(+) ─→ 电池盒 ─→ TP4056 IN+ / IN-
  TP4056 OUT+ / OUT- ─→ MT3608 IN+ / IN-
  MT3608 OUT+(5V) ─→ 面包板电源模块 5V 输入
                       └→ STM32 USB 口
                       └→ HC-SR04 VCC（如有）

  先万用表调 MT3608 输出 5V，再接开发板！
```

### 8.7 串口调试环境

本地 Hermes 需要：
- Python 3 + pyserial (`pip install pyserial`)
- Arduino IDE 或 PlatformIO（烧录 STM32/ESP32）
- STM32 烧录工具：STM32CubeProgrammer 或 stm32flash

常用命令：
```bash
# 读串口
screen /dev/ttyUSB0 115200
# 或
python3 -m serial.tools.miniterm /dev/ttyUSB0 115200
```
